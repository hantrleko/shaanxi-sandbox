# 陕西省地理人文 3D 互动沙盘 (Shaanxi Geography & Humanities Sandbox)

> 基于 WebGL / Three.js + Vue 3 构建的探究式地理人文三维数字互动沙盘系统。  
> 灵感源自 Moby（@readyfor2025）的互动沙盘设计理念（“人 8 小时 + AI 50 小时”生产工作流）。

---

## 🌟 核心特性与功能

1. **宏观 3D 全省沙盘 (Macro Sandbox Mode)**
   - **立体高程阶梯**：生动展现陕北黄土高原、关中渭河平原（八百里秦川）、陕南秦巴山地三大自然区。
   - **地理矢量网络**：发光省界多边形外框、黄河/渭河/汉江三大水系流动管线、丝绸之路起始段金色流光轨迹。
   - **3D POI 浮标联动**：西安（长安）、华山、太白山、兵马俑、壶口瀑布、延安宝塔山等三维悬浮徽章，点击平滑飞向目标。
   - **电影级运镜漫游**：基于 GSAP 实现镜头在各段落间自动俯冲、旋转、聚焦。

2. **微观盆景切块 (Bonsai Mode · 3D Blocks)**
   - 从全省大地图中“剥离切出”局部高精地形立方体切块。
   - 带有地层剖面厚度、3D 海拔刻度立柱标尺（如华山 2154m 拔地而起、壶口瀑布峡谷下切、太白山拔仙台 3771m）。
   - 支持 **1.0x ~ 2.5x 垂直高差放大倍数** 实时交互调节。

3. **科学地貌演变模型 (Evolutionary Model)**
   - **黄土高原千沟万壑 7 阶段动态演进**：
     1. 深厚黄土堆积 ➔ 2. 原始完整黄土塬 ➔ 3. 暴雨细沟下切 ➔ 4. 黄土梁形成 ➔ 5. 黄土峁孤丘出现 ➔ 6. 现代千沟万壑 ➔ 7. 当代生态梯田治理。
   - 伴随流水冲刷侵蚀动态矢量箭头与网格形态平滑过渡。

4. **剧场式章节导览与语音播放器**
   - 顶部状态胶囊（待播放 / 讲解中）。
   - 左侧深度图文知识浮窗（时代特征、核心要点、剖面示意图、实景卫星图）。
   - 底部段落流卡片（支持“讲解全部”连播、上一段/下一段）。
   - 内置 Web Speech API 真人语音合成伴听。

## 🚀 运行与预览

当前 Vite 开发服务器已在本地启动：
- 本地访问地址：`http://localhost:5173/`

日常启动命令：
```bash
cd E:\Project\shaanxi-sandbox
npm run dev
```

构建生产版本：
```bash
npm run build
```
